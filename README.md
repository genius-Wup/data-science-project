# Student Performance Analysis: What Factors Affect Final Grades?

 1. Problem / Research Question
This project investigates which factors are most strongly associated with students' final grades. The research question is: What factors (study time, attendance, parental education, etc.) are most strongly associated with students' final grades?

2. Dataset Source and Usage Permissions
- Source: Kaggle - Student Performance Dataset
- Link: https://www.kaggle.com/datasets/(https://www.kaggle.com/datasets/fares279/student-performance-factors)
- Permission: Publicly available for educational use
- Note: No personal or restricted data is included. The dataset is anonymized.

## 3. Methods and Tools
- Language: Python
- Libraries: pandas, numpy, matplotlib, seaborn, scikit-learn
- Methods:
  - Data cleaning and preprocessing
  - Exploratory data analysis (EDA)
  - Correlation analysis
  - Data visualization
  - Basic regression / classification

## 4. Key Findings and One Limitation
### Key Findings
- Students who study more hours per week tend to achieve higher final grades.
- Attendance rate shows a positive correlation with final performance.
- Past failures have a negative relationship with final grades.

### Limitation
- The dataset is relatively small and comes from a limited number of schools, so the findings may not generalize to all student populations.
